# bwoodwork frontend

A react frontend for my woodworking portfolio.

## Technologies

### React Router 7 Library

React router 7 library gives me all the routing functionality I need without the opinionated choices of the framework. It still feels like base react.

### TailwindCSS

Tailwind is an easy choice for me. When incorporating layouts and variables, it brings the benefits of localized styling, without the multi file abstractions of pure css. Aditionally, it makes prototyping much, much faster.

### shadcn

I use shadcn for almost every project. I appreciate owning the component code, and the default just look visually appealing.
